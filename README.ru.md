# aliexpress-ru-mcp

[English](README.md) · **Русский**

> Сервер для покупателя: работает с публичной витриной aliexpress.ru, аккаунт не нужен.

[MCP](https://modelcontextprotocol.io)-сервер, который даёт LLM-агентам
актуальные данные с [aliexpress.ru](https://aliexpress.ru) — российской витрины
AliExpress — и честно подписывает, что это за данные. Есть цены в рублях по
каждому варианту товара, купоны с реальным порогом суммы заказа, даты и
стоимость доставки в российский город, продавцы и отзывы с настоящей пагинацией.

## Зачем ещё один сервер для AliExpress

Большинство парсеров AliExpress либо работают с aliexpress.com (доллары, без
доставки в Россию и без рублёвых купонов), либо отдают не те цифры, которые
платит покупатель. Этот сервер построен так, чтобы этого не делать:

| Ловушка | Что делает сервер |
|---|---|
| «Цена» берётся из диапазона min–max по всем вариантам карточки и оказывается ниже той, что показана на странице | Цена варианта, который карточка выбирает по умолчанию (или того, что вы попросили), плюс все варианты с их опциями, ценой и остатком |
| Выдача показывает цену другого варианта, чем карточка (пример: набор из 2 шт. за 499 ₽, а карточка открывается на 1 шт. за 299 ₽) | У каждого товара в выдаче указан вариант, к которому относится цена (`listing_sku_id`); `get_product` по запросу считает именно его |
| Купон вычитается из цены одной вещи, хотя срабатывает только от суммы заказа, например от 908 ₽ | Все купоны с минимальной суммой заказа; применяется только то, что открывает заказанное количество (один купон магазина + один порог скидки от суммы заказа), и показывается следующий порог |
| Пустая доставка: страна отправки подставляется как «RU», и API отвечает «способов нет» | Запрос доставки делается ровно так, как его делает страница товара; пустой ответ отдаётся как «неизвестно», а не как «бесплатно» |
| Доставка считается не для того города (регион хранится в куке) | Регион выставляется в каждом запросе, а город, который вернул сайт, сверяется с запрошенным |
| Лот из 100 штук сравнивается с одной штукой (флаг `lot` в ответе API остаётся false даже на карточках лотов) | Размер лота берётся из подписи единицы на самой карточке («Цена за 1 лот (100 штук)») |
| Товары `/item/1_XXXX.html` не открываются по голому id | `source_id` учитывается везде и исправляется автоматически |
| «Продавцы не заполняют характеристики» — на самом деле их грузит отдельный асинхронный виджет | Характеристики (и по желанию описание) берутся из того же эндпоинта виджетов, что использует страница |
| Доступна только первая страница текстов отзывов | Настоящая пагинация отзывов, сортировка «сначала с низкой оценкой», фильтры по звёздам, фото и «из России» |
| Дальние страницы поиска повторяют уже показанные товары | Страницы связываются токеном продолжения, который использует сам сайт |
| Капча антибота, заблокированная сессия | Headless Chromium один раз получает сессию; заблокированная сессия перевыпускается автоматически, иначе возвращается понятная ошибка |

В каждом ответе есть `fetched_at`, а в ответах с ценами и доставкой — город,
для которого они получены.

## Инструменты

| Инструмент | Что возвращает |
|---|---|
| `search_products(query, page, sort, price_min, price_max, limit, city)` | По 20 товаров на страницу; сортировки `relevance` / `orders` / `price_asc` / `price_desc` / `newest`; `total_found`, `has_more`. По каждому товару: цена в выдаче и цена до скидки вместе с вариантом, к которому они относятся (`listing_sku_id`), цена «с купоном» из выдачи, рейтинг, число покупок, оценка доставки из выдачи, число вариантов, признаки Choice и рекламы, продавец, `item_id`, `source_id`, ссылка |
| `get_product(item_id, source_id, sku_id, quantity, city, include_description)` | Выбранный вариант (цена, цена до скидки, остаток, опции); все варианты; все купоны с порогами; что дают купоны при `quantity` штук и следующий порог; условия комбо-корзины Choice; способы доставки с датами и стоимостью в город; рейтинг с распределением звёзд; число покупок; продавец (процент положительных отзывов, подписчики, бейджи, отправленные заказы, срок работы магазина); характеристики; защита покупателя и возврат |
| `get_reviews(item_id, source_id, sort, stars, with_photos, from_russia, with_follow_up, page, limit, include_aspects)` | Отзывы: дата, оценка, текст и оригинал текста, купленный вариант, число фото, «полезно», страна покупателя, ответ продавца, дополнение к отзыву; распределение звёзд; аспект-теги AliExpress («Яркий свет» — 16 упоминаний, 100 % положительных) |
| `compare_products(items, city)` | До 10 товаров рядом: цена, вариант, диапазон цен, цена после купонов за 1 шт., самая дешёвая и самая быстрая доставка, рейтинг, отзывы, покупки, признаки |

## Требования

| | |
|---|---|
| Python | ≥ 3.10 и [uv](https://docs.astral.sh/uv/) (или pip) |
| Браузер | Chromium для Playwright, скачивается сам при первом запуске (≈300 МБ загрузки, ≈650 МБ на диске в `~/.cache/ms-playwright`, общий для всех инструментов на Playwright). Прогревает сессию aliexpress.ru несколько секунд при первом запуске и повторно, если антибот её заблокирует; все запросы за данными — обычный HTTP |
| Docker | Не нужен: Chromium запускается как дочерний процесс сервера прямо в системе |
| Системные библиотеки | Уже есть в настольном Linux, macOS и Windows. На минимальном сервере Debian/Ubuntu поставьте их один раз (нужен root): `uvx --from playwright playwright install --with-deps chromium` |
| Сеть | В наших проверках aliexpress.ru отвечал и с зарубежного IP; доставка всегда считается в российский город из `AE_CITY` |
| Память | Браузер занимает ≈1 ГБ, пока работает, — ≈10 с прогрева (замер на холодном старте), потом закрывается |
| Дисплей | Не нужен (`AE_HEADLESS=0` показывает окно, чтобы решить капчу вручную) |
| Проверено на | Linux (CachyOS; Playwright ставит туда сборку для Ubuntu). macOS и Windows Playwright поддерживает, но там не проверялось |

## Установка

Claude Code:

```bash
claude mcp add aliexpress -e AE_CITY=Москва -- uvx --from git+https://github.com/SZhukovWork/aliexpress-ru-mcp aliexpress-ru-mcp
```

Любой MCP-клиент (`claude_desktop_config.json`, `.mcp.json` и т. п.):

```json
{
  "mcpServers": {
    "aliexpress": {
      "command": "uvx",
      "args": ["--from", "git+https://github.com/SZhukovWork/aliexpress-ru-mcp", "aliexpress-ru-mcp"],
      "env": {"AE_CITY": "Москва"}
    }
  }
}
```

Из клона репозитория: `uv venv && uv pip install -e . && .venv/bin/aliexpress-ru-mcp`.

## Настройка (переменные окружения)

| Переменная | По умолчанию | Смысл |
|---|---|---|
| `AE_CITY` | `Москва` | Город для цен и расчёта доставки, как он называется на сайте. Для городов-тёзок добавьте регион: `Кировск, Мурманская`. Каждый инструмент также принимает аргумент `city` |
| `AE_PROXY` | — | Прокси для HTTP и браузера, например `http://user:pass@host:3128` |
| `AE_MIN_INTERVAL` | `1.0` | Пауза в секундах между запросами к aliexpress.ru. Сайт троттлит частые запросы |
| `AE_CACHE_DIR` | `~/.cache/aliexpress-ru-mcp` | Антибот-сессия (файл с правами 0600) и найденные города |
| `AE_HEADLESS` | `1` | `0` открывает видимое окно браузера при получении сессии. Нужно один раз, если сайт показал капчу: решите её, и сессия будет переиспользоваться |

## Что означают цифры

- **`price_rub`** — цена варианта для анонимного покупателя прямо сейчас («цена
  сейчас» на карточке); `price_before_discount_rub` — зачёркнутая цена. Варианты
  одной карточки могут сильно различаться по цене, поэтому ответ всегда называет
  вариант (`sku_id`, `options`).
- **Купоны** срабатывают от суммы всего заказа. `with_coupons` применяет только
  купоны, которые открывает заданное количество `quantity`; `next_threshold`
  говорит, на сколько нужно дозаказать ради большей скидки. Купон магазина нужно
  забрать на карточке (бесплатно, одним нажатием) — это `needs_claim`.
  `site_card_coupon_price_rub` — собственная цифра карточки «X ₽ с купоном»; если
  она расходится с расчётом по порогам, ответ об этом сообщает. Скидки
  `multi_piece` («−2 % от 3 шт.») перечислены, но в итог не входят: как они
  складываются с купонами, не проверено.
- **Цены в поиске** относятся к варианту, который показывает выдача
  (`listing_sku_id`); карточка может по умолчанию выбрать другой, дешевле или
  дороже. Чтобы оценить тот же вариант, передайте `listing_sku_id` в `get_product`
  как `sku_id`. Ценовое окно фильтрует по собственному полю цены AliExpress,
  поэтому показанная цена может выходить за его границы.
  **`listing_coupon_price_rub`** — цена «с купоном», которую рекламирует
  выдача; купону может понадобиться заказ побольше.
- **Товары комбо Choice** (`combo`): цена карточки и бесплатная доставка обещаны
  для заказов в комбо-корзине от порога (обычно 1 000 ₽). Если заказ меньше,
  ответ предупреждает, что он может выйти дороже, и приводит цену API «купить
  сейчас» для одного этого варианта; на оформлении заказа это не проверено.
- **`delivery`** — настоящий расчёт для города: способы, диапазон дат,
  стоимость, нужен ли паспорт. Пустой список способов значит «неизвестно», а не
  «бесплатно». **`delivery_estimate`** в поиске — сводка из выдачи
  (`cost_rub_from` — самый дешёвый способ, `days` — диапазон из выдачи).
- **Рейтинг** относится ко всему товару (ко всем вариантам вместе).
  **`orders`** — счётчик «купили», то есть покупки, а не отзывы.
- **Продавец**: `positive_feedback_percent` — рейтинг продавца с карточки;
  `badges`: `brand` (сертифицированный представитель бренда), `official`
  (собственная марка продавца), `top` (магазин в топе); `orders_shipped` вместе с
  `orders_shipped_period` — самое близкое к сроку работы магазина, что показывает сайт.
- **`lot`** / **`lot_pieces`**: карточка продаёт лотами («Цена за 1 лот (100 штук)»),
  и все цены на ней — за лот. `price_unit` повторяет подпись единицы с карточки.
- **`stock`** — точное число из API (карточка округляет до «99+»).
- **`fulfilment`**: `own_warehouse` — отправка со склада AliExpress (Choice);
  `dropshipping` — отправляет продавец (наблюдаемые значения).
- Отзывы на других языках AliExpress переводит машинно; оригинал лежит в `original_text`.

## Ограничения

- Неофициальный API: сервер опирается на внутренние эндпоинты сайта, их могут
  изменить в любой момент. Разбор ответов изолирован в `parse.py` и покрыт
  тестами на записанных ответах.
- Только анонимно: залогиненный покупатель может видеть персональные цены и
  купоны (для новых пользователей, программы лояльности). Окончательную сумму
  показывает только оформление заказа.
- Проверено с российского IP. После множества новых сессий с одного IP антибот
  может показать капчу даже браузеру: подождите или запустите один раз с `AE_HEADLESS=0`.
- Сортировка поиска по цене и ценовое окно работают по собственному полю цены
  AliExpress, поэтому показанная цена может выходить за границы окна (см. «Что означают цифры»).
- Отзывы приходят по 10 за запрос; фильтр по звёздам принимает одно значение за раз.
- Только чтение: без аккаунта, корзины и заказов (см. «Планы»).

## Планы

- **Позже: необязательный режим аккаунта** (выключен по умолчанию). Вход один раз
  в видимом окне браузера — логин и пароль не проходят через MCP-клиент. Даст ваши
  персональные цены, забранные купоны и точную доставку по вашему адресу.
- **Позже: корзина** — `add_to_cart` / `get_cart` поверх режима аккаунта, чтобы
  точно проверять суммы с купонами и комбо.
  Оформление заказа, оплата и смена адреса сознательно не входят в планы.

## Разработка

```bash
uv venv && uv pip install -e '.[dev]'

```

## Оговорка

Проект не связан с AliExpress и Alibaba Group. Предназначен для личного
сравнения цен; соблюдайте пользовательское соглашение aliexpress.ru и не
повышайте частоту запросов.
